# weread.koplugin · 个人 UI 定制版（fork）

基于 [finlater/weread.koplugin](https://github.com/finlater/weread.koplugin) v1.4.2 的界面定制分支，**与 SimpleUI 深度整合**：让 weread 书架看起来、用起来和 SimpleUI 的界面是同一套。仅供个人学习使用，许可证 AGPL-3.0（来源与免责声明见上游 [README.md](README.md) / [NOTICE](NOTICE)）。

## 与上游的区别

- **界面统一到 SimpleUI**：顶部让位给 SimpleUI 状态栏，底部使用 SimpleUI 的导航栏（书库 / 主页 / 电源等），在 weread 页内即可直接切换，来回切换不跳变。
- **交互沿用 SimpleUI 与 KOReader 原生**：顶部点击 / 下滑呼出 KOReader 原生主菜单；左缘或双指上下滑调前光并以原生通知反馈；任何 KOReader 原生菜单弹出时，下方页面按 Kindle 样式压暗；长按标题栏或分页器即打开对应的 SimpleUI 设置窗口。
- **阅读统计页同套体验**：从 dock 打开时自带状态栏与导航栏外壳；在阅读器内打开则保持官方全屏样式。
- **本地书库（文件管理）头部与书架对齐**：标题、分隔线、操作图标行、封面网格留白与封面下书名，均与书架页同一套规格。
- **上游功能不变**：登录、书架、下载、阅读、同步、划线想法等全部保持原样。

## 依赖

- KOReader ≥ 2026.03
- SimpleUI

## 安装

1. 用本仓库内容替换 Kindle 上的插件目录：将本目录整体拷贝覆盖到 `koreader/plugins/weread.koplugin/`。
2. 重启 KOReader。

## 首次配置：在 SimpleUI 里放一个「weread」入口

本 fork 的 weread dock 读取你的 SimpleUI dock 配置。要让「weread」出现在 weread 页内底部导航栏上：

1. 在 SimpleUI 的 dock 里添加一个快捷项指向本插件（插件 → weread）。
2. 打开 weread 书架时，底部导航栏会按 SimpleUI 的顺序显示同样几项，其中 weread 项高亮为当前页。

## 使用

### 离开与切换

顶部标题栏没有 ✕ 关闭按钮，离开 weread 用底部导航栏：

- **书库 / 设置 / 历史**：离开 weread 并跳到 SimpleUI 对应屏；
- **主页**：直接切到 SimpleUI 主页；
- **电源**：在 weread 页内弹出电源菜单（重启 / 休眠 / 退出），退出会正常保存数据；
- **weread**：当前页，无操作并保持高亮。

### 长按标题栏打开该栏设置

在书架页或统计页**长按标题区域**（标题文字、分隔线、标签行 / 操作行、空白处）即打开 SimpleUI 的「标题栏」设置窗口，与本地书库的长按行为一致；窗口标题与内容都来自 SimpleUI，跟随界面语言。改完无需切页即可看到效果（例如其中的尺寸档位会立即作用于页内的标签与操作行）。

### 底部导航栏的翻页箭头（navpager）

SimpleUI 的 navpager 打开时，底部导航栏两端出现箭头，行为与 SimpleUI 自身页面一致：

- **点击**箭头：书架页翻页；统计页切换上一 / 下一周期；
- **长按**箭头不松手：书架页跳到首页 / 末页；统计页长按右箭头直达最新周期；
- 此时页面内**不再显示**分页行（书架 / 公众号）与周期行（统计）。

navpager 关闭时相反：底部导航栏没有箭头，翻页与周期切换回到页面内的分页行 / 周期行。

### 阅读统计页

- 从书架或任意 SimpleUI 屏的 dock 点统计：带状态栏与底部导航栏外壳直达；统计页 dock 点「微信读书」回书架；
- 在阅读器内打开统计：保持官方全屏样式。

### 手势

- **顶部带**（SimpleUI 状态栏所在区域）点击或下滑：呼出 KOReader 原生主菜单（记忆上次标签页）；
- **左缘 1/8 上下滑** 或 **双指上下滑**：调整前光，原生通知反馈当前亮度。

### 页码导航

书架 / 公众号与本地书库为同款样式；只有一页时不显示。

- **点击**中间的 `x/y`：弹出页码输入框（KOReader 原生），输入页码确认即跳转；本地书库的分页器同样如此；
- **长按** `x/y` 或四个箭头、**松手后**：打开 SimpleUI 的「分页栏」设置窗口（书架页与本地书库都支持）；
- 四个箭头单击仍是首页 / 上一页 / 下一页 / 末页；
- 以上只在 navpager 关闭时可用——navpager 打开时页面内不显示分页行，翻页由底部导航栏箭头承担。

### 菜单遮罩

任何 KOReader 原生菜单（书架 / 文件管理 / 阅读页）弹出时，下方页面按 Kindle 样式压暗，菜单关闭即还原。这是本插件在启动时生效的全局行为，禁用或卸载插件后不再生效。

## 已知限制

- **统计页内容区左缘单指调光不可用**（与内容滚动共用同一手势通道，物理冲突）；统计页可用双指调光，书架页左缘单指调光正常。
- **SimpleUI 顶部下拉面板的电源 → 退出**，在遮罩启用且 weread 全屏页在场时可能卡住（SimpleUI 面板未适配第三方全屏页叠加）。**请改用底部导航栏的电源退出**（页内电源菜单，正常）。
- **e-ink 残影**：原生菜单「长 → 短」切换的瞬间，让出区域可能残留旧帧，关闭菜单即恢复，不影响使用。
- **外观跟随范围**：底部导航栏与顶部状态栏由 SimpleUI 自己渲染，因此 weread 页内使用你在 SimpleUI 中的相关外观设置；页面内的标签与操作行跟随 SimpleUI「标题栏 → Button Size」的尺寸档位（与分隔线对齐的左右边距不随档位缩放）；分页行与周期行沿用本 fork 的固定规格。
